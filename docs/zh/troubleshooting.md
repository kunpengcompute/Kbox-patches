## 32位APP类故障处理<a id="ZH-CN_TOPIC_0000002518226310"></a>

### 现象描述<a id="section6713450123511"></a>

32位APP出现问题，而64位APP正常，如：APP无法打开、APP打开闪退等问题。

### 对系统的影响<a id="section1883411169412"></a>

影响所有32位APP的运行。

### 可能原因<a id="section1777888184213"></a>

单独出现32位APP故障，很可能是转码软件出现故障，可能的原因包括：

1. 转码软件没有注册成功。
2. 转码软件版本不匹配。
3. 转码软件配套补丁未合入。

### 操作步骤<a id="section12646853105012"></a>

1. <a id="li1655995125318"></a>执行如下命令检查回显信息是否正常，显示“enable”为正常。

    ```bash
    cat /proc/sys/fs/binfmt_misc/ubt_a32a64
    ```

2. 若回显信息异常，执行如下命令重新注册。

    ```bash
    echo ":ubt_a32a64:M::\x7fELF\x01\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00\x02\x00\x28\x00:\xff\xff\xff\xff\xff\xff\xff\x00\x00\x00\x00\x00\x00\x00\x00\x00\xfe\xff\xff\xff:/opt/exagear/ubt_a32a64:POCF" > /proc/sys/fs/binfmt_misc/register
    ```

3. 返回[1](#li1655995125318)，再次检查回显信息是否正常。
4. 执行如下命令检查转码软件版本。

    ```bash
    /opt/exagear/ubt_a32a64 -V
    ```

5. 将显示的软件版本，和版本配套说明书中的转码软件版本进行比对，若版本不匹配，请联系技术支持获取匹配的软件版本。

    若问题仍未解决，请进行信息收集，并联系技术支持处理。

## 补丁合入类故障处理<a id="ZH-CN_TOPIC_0000002518386224"></a>

### 现象描述<a id="section111416358916"></a>

镜像编译失败，镜像编译出现额外的告警信息。

### 对系统的影响<a id="section1188785910917"></a>

无法编译出正常的镜像，业务无法运行。

### 可能原因<a id="section393416205106"></a>

1. 补丁合入失败。
2. 补丁合入出现了遗漏。
3. 补丁版本和源码版本不匹配。

### 操作步骤<a id="section89841336161010"></a>

1. 查找编译目录下的“.rej”文件，命令如下。

    ```bash
    find ./ -name "*.rej"
    ```

    若能找到，不带.rej的同名文件即为有问题的文件，此时应联系技术支持进行处理。

2. 检查源码的版本，并与版本配套说明书中的版本进行匹配，若版本不匹配，应将源码调整为版本配套说明书所指明的版本。

## 宕机类故障处理<a id="ZH-CN_TOPIC_0000002518386232"></a>

### 现象描述<a id="section55241852162719"></a>

服务器在某些使用场景下出现了宕机问题。

### 对系统的影响<a id="section69995352720"></a>

系统完全不可用，服务中断。

### 可能原因<a id="section854711548271"></a>

1. 软件版本不匹配。
2. 服务器配置不正确。

### 操作步骤<a id="section12953654202714"></a>

请参见[配置BIOS](install_guide.md#配置BIOS)章节，检查内存及BIOS配置。
