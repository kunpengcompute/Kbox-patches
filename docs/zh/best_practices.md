# 最佳实践<a name="ZH-CN_TOPIC_0000002521463656"></a>

## 实践1：使能自适应Vsync降低端到端操作时延<a name="ZH-CN_TOPIC_0000002549833663"></a>

### 介绍

云手机/云游戏端到端操作时延是决定用户体验的关键因素之一。Boostkit Kbox组件提供自适应Vsync功能，优化服务端安卓图形子系统vsync机制，降低图像在渲染-抓图阶段的时延，经验证在主流游戏场景可降低端到端操控时延。

#### 建议版本

Boostkit Kbox 7.2.RC1及以上版本。

### 环境准备

本次实践需要部署云手机服务端+客户端，保证云手机可正常出流。

1. 根据《部署安装指南》文档，部署视频流云手机（7.2.RC1及以上版本）。
2. 手机安装出流客户端，或其他形态的出流方式，确保可正常出流并操作云手机。

**网络传输时延对端到端时延影响较大，为保证下面步骤中能够测出稳定的端到端时延并对比功能优化效果，建议确保云手机出流使用的网络状态稳定。**

### 特性使能

1. `cd /home/kbox_video`
2. `docker cp android_1:/system/vendor/build.prop .`
3. `echo "ro.vmi.adaptive.vsync=1" >> build.prop`
4. `docker cp build.prop android_1:/system/vendor/build.prop`
5. `./cfct_video restart 1`
6. 观察logcat日志中是否有"`Enabling adaptive vsync.`"，若有则说明成功使能自适应vsync。

> 说明：
>
> 1. android_1为样例云手机容器名，根据实际调整
> 2. 自适应vsync功能在ro.vmi.adaptive.vsync属性配置为1时使能，亦可使用其他方式（如编译安卓镜像时指定属性的值）使其在容器启动时生效

### 效果验证

1. 按《环境准备》、《特性使能》章节部署视频流云手机。
2. 打开手机十字线光标显示（确保在点击时本地屏幕会显示十字线）。运行常见游戏应用，如原神，进入游戏后在某一固定位置保持静止
3. 云机出流
4. 准备一个秒表（或另一个手机运行秒表应用），开始计时
5. 使用支持120/240fps的拍摄设备，同时录制出流手机画面和秒表，确保出流手机画面、秒表时钟在录制画面中不受遮挡
6. 快速点击游戏按钮，重复多次，中间停顿5s，完成点击后结束录制。
7. 在录制的画面中，找到每一次点击，十字线开始显示的时间，到画面中按钮被点击后发生反应的时间间隔，记为点击时延。取多次点击的平均时延。
8. 使能自适应vsync功能后，重复2~7步骤，并记录自适应vsync生效后的平均点击时延。
9. 对比自适应vsync功能使能前后测得的平均点击时延，即可观察自适应vsync功能对端到端时延的优化效果。
