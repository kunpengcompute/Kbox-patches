## 补丁合入类故障处理<a name="ZH-CN_TOPIC_0000002518353828"></a>

**现象描述<a name="section111416358916"></a>**

镜像编译失败，镜像编译出现额外的告警信息。

**对系统的影响<a name="section1188785910917"></a>**

无法编译出正常的镜像，业务无法运行。

**可能原因<a name="section393416205106"></a>**

1. 补丁合入失败。
2. 补丁合入出现了遗漏。
3. 补丁版本和源码版本不匹配。

**操作步骤<a name="section89841336161010"></a>**

1. 查找编译目录下的“.rej“文件，命令如下。

    ```
    find ./ -name "*.rej"
    ```

    若能找到，不带.rej的同名文件即为有问题的文件，此时应联系技术支持进行处理。

2. 检查源码的版本，并与版本配套说明书中的版本进行匹配，若版本不匹配，应将源码调整为版本配套说明书所指明的版本。
